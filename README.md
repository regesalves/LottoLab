# LottoLab

Aplicativo desktop para geração e análise de jogos da Lotofácil.

O LottoLab usa React, TypeScript, Vite e Electron para oferecer uma interface local de seleção de dezenas, aplicação de critérios e geração de jogos.

## Objetivo

Auxiliar a criação de combinações da Lotofácil com filtros configuráveis e análise baseada no histórico de concursos.

## Desenvolvimento

```bash
npm run dev
```

## Testes

```bash
npm test -- --test-reporter=spec
```

## Build desktop

```bash
npm run build
```
